# Gesture Cam

Primeira versão do experimento de visão computacional com webcam.

## V1
- câmera frontal
- MediaPipe Hand Landmarker
- rastreamento de mão em tempo real
- esqueleto com os 21 pontos
- indicador destacado
- gesto com apenas o indicador levantado ativa desenho no ar
- pinça entre polegar e indicador detectada
- otimização mobile: 1 mão e resolução reduzida

## Publicação
Projeto pronto para GitHub Pages a partir da branch `main`, pasta raiz `/`.
